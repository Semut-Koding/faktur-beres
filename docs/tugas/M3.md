## Batasan keras
Semua aturan di CLAUDE.md berlaku. Khusus M3:
- **Hanya data sintetis yang dikirim ke Gemini.**
  - Yang boleh dikirim hanya berkas di `eval/berkas/` dan `eval/ketahanan/berkas/`, frasa di set injeksi, dan berkas yang dibuat tes.
  - Alat CLI ekstraksi menolak path di luar repo. Pengecualiannya hanya `eval:injeksi --berkas`, untuk set tertutup perencana.
  - Semua alat yang mengirim ke LLM menolak path dengan komponen `_privat` atau `privat`.
  - Nama berkas tidak dikirim ke LLM.
- **Prompt LLM tidak memuat label maupun data ERP.**
  - Yang tidak boleh ada: ID skenario, kategori, varian, jawaban yang diharapkan, nama vendor, nomor PO, NPWP, dan rekening dari dataset. Ada tes yang memeriksanya.
  - Prompt tidak boleh disetel dengan petunjuk untuk dokumen tertentu. Perubahan prompt harus berlaku umum, dan setiap perubahan menaikkan versi prompt.
- **LLM tidak menghitung** (ADR-0005). Ekstraksi mengembalikan teks persis seperti tercetak; kode yang membaca angka, menghitung, dan memutuskan.
- **Kode agent terpisah dari kode evaluasi.**
  - `faktur_beres.llm` dan `faktur_beres.extraction` adalah kode agent, dengan aturan yang sama seperti `domain` dan `tools`. Perluas `tests/test_architecture.py`.
  - `faktur_beres.domain` tidak mengimpor `llm`, `extraction`, atau `tools`.
- **API key Gemini tidak pernah tampil** di log, laporan, keluaran perintah, cache, maupun pesan galat. Log DEBUG pustaka HTTP tidak diaktifkan.
- **Panggilan LLM dalam jumlah banyak dijalankan setelah memberi tahu pemilik.** Ini mencakup uji banding, `eval:injeksi` dengan LLM, dan run segar `eval:ekstraksi`.
  - Sebutkan perkiraan jumlah panggilan per model dan perkiraan waktunya, lalu tunggu persetujuan.
  - Selama pengembangan, panggilan dibuat sedikit dan memakai `--pakai-cache`.
- **Label, dataset, dan berkas di `eval/skenario/` serta `eval/berkas/` tidak diubah.**
  - Bila aturan dan label bertentangan, berhenti dan laporkan.
  - Berkas baru di `eval/ketahanan/` dan `eval/injeksi/` dibuat oleh tugas ini.
- **Uang, kuantitas, persentase, dan biaya LLM memakai `Decimal`.** `float` tidak dipakai.
- **Tanpa tabel aplikasi.**
- **Commit kecil** dengan pesan `M3.x ringkasan`.

## Kapan berhenti dan bertanya
- `GEMINI_API_KEY` kosong saat langkah LLM tiba. Minta pemilik mengisinya di `.env`, bukan menempelkannya di chat.
- `llm:model --uji` tidak menemukan Flash-Lite atau Flash stabil yang bisa dipakai key pemilik.
- Di uji banding, Flash lebih akurat lebih dari 2 poin persentase.
- Kuota habis berulang, sehingga run segar penuh tidak selesai dalam 2 hari.
- Orakel tidak 40/40 setelah perubahan, karena aturan bertentangan dengan label, bukan karena bug pola.
- Parser UBL tidak bisa 100% karena SPEC §15.6 berbeda dengan berkas generator.
- Ada kebutuhan mengubah dataset, label, atau berkas di `eval/skenario/` dan `eval/berkas/`.
- Akurasi hanya bisa diperbaiki dengan petunjuk khusus dokumen di prompt.
- Baris `res.bank` di `odoo:check` gagal tanpa mengubah addon.
- Dibutuhkan `sudo`, ada port bentrok, atau ada langkah yang menyentuh milik `dombatek`.
- Ada pilihan yang berdampak ke SPEC atau ADR di luar perubahan yang diminta di sini.
