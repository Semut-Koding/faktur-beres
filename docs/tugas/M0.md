## Kriteria selesai
1. Repo git dengan commit kecil. Dokumen fondasi menjadi commit pertama.
2. Perintah berikut bekerja: `npm run setup`, `services:up`, `services:down`, `services:status`, `services:logs`, `odoo:init`, `odoo:seed`, `odoo:check`, `odoo:snapshot`, `odoo:reset`, `check`, dan `guard:secrets`.
3. Dari database kosong: `odoo:init` → `odoo:seed` → `odoo:check` lulus semua. `odoo:seed` dan `odoo:init` yang dijalankan kedua kali tidak mengubah apa pun (dibuktikan).
4. `odoo:reset` mengembalikan kondisi seed dalam kurang dari 1 menit (dibuktikan).
5. Key agent bisa membaca PO, penerimaan, rekening, dan tagihan lewat JSON-2. Hak hapus dan posting yang ikut dimiliki user agent tercatat di laporan, tanpa benar-benar menghapus atau memposting apa pun.
6. `npm run check` lulus, termasuk tes klien JSON-2, tes dataset, dan tes guard rahasia.
7. Dokumen diperbarui sesuai kenyataan, dan M0 ditandai selesai di RENCANA-TEKNIS §6.
8. Laporan sesuai format di `docs/tugas/README.md`.

Untuk pilihan kecil yang tidak berdampak ke dokumen, putuskan sendiri dan catat di laporan.

## Laporan
Ikuti format di `docs/tugas/README.md`. Untuk M0, sertakan juga:
- tabel versi alat dan tag image persis yang dipakai (beserta digest);
- tabel hasil `odoo:check`;
- bukti idempoten `odoo:init` dan `odoo:seed` (keluaran kedua kali dijalankan);
- waktu `odoo:reset`;
- grup user agent dan hak yang ditemukan (baca, buat, hapus, posting);
- pilihan pajak pembelian dan alasannya;
- tabel nama field Odoo 19 yang dipakai;
- hasil uji path berspasi (`uv run pytest` dibanding `python -m pytest`);
- bukti daftar kontainer non-`fakturberes` tidak berubah.
